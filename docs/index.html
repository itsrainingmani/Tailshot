Tailshot

Send browser images to your own devices.

Tailshot adds a right-click action for images in Chrome and sends the selected image through your local Tailscale Taildrop setup.

Install native host Privacy policy GitHub

How It Works

  1. Right-click an image in Chrome.
  2. Choose Send with Tailscale.
  3. Pick one of your Taildrop-capable devices.
  4. Tailshot passes the selected image to the local Tailscale CLI.

Requirements

  • Tailscale installed and signed in on the sending computer.
  • Taildrop enabled for your tailnet.
  • The Tailshot native host installed locally.
  • A destination device that can receive Taildrop files.

Privacy

Tailshot handles an image URL and image bytes only after you explicitly choose the context menu action and grant access to that image's origin if Chrome asks. It does not upload data to Tailshot-operated servers, sell data, or use analytics services.
