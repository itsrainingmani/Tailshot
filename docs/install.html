Install Tailshot Native Host

Tailshot uses Chrome native messaging so the extension can pass selected images to the local Tailscale CLI.

Windows

  1. Download the latest tailshot-windows-1.1.zip package from the project's GitHub release.
  2. Extract the zip.
  3. Install the Chrome extension and copy its extension ID.
  4. Run the installer from PowerShell:
powershell -ExecutionPolicy Bypass -File .\install.ps1 -ExtensionId EXTENSION_ID -Browser Chrome

The installer copies the native host to %LOCALAPPDATA%\Programs\Tailshot and registers Chrome native messaging under HKCU. It does not require administrator privileges.

Test

  1. Restart Chrome after installing the native host.
  2. Open any normal web page with an image.
  3. Right-click the image.
  4. Choose Send with Tailscale.
  5. Select a Taildrop-capable device.

Troubleshooting

  • Run tailscale status to confirm Tailscale is connected.
  • Run tailscale file cp --targets to confirm Taildrop targets are available.
  • Check %LOCALAPPDATA%\Programs\Tailshot\debug.log for native host logs.
